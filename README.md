# AI CSV Cleaner 🚀

An AI-powered tool that cleans messy CSV files, generates insights, and helps users analyze data easily.

---

## 🔥 Features

- Clean missing values automatically  
- Remove duplicate records  
- Visual comparison of raw vs cleaned data  
- AI-powered data insights  
- Chat with your dataset in plain English  
- Export cleaned data in CSV, JSON, TXT, and PDF formats  

---

## 🎯 Problem It Solves

Messy and unstructured data slows down data analytics and lead generation. This tool helps transform raw data into clean, structured, and analysis-ready datasets in seconds.

---

## 🛠️ Tech Stack

- Python  
- Streamlit  
- Pandas  
- AI Integration (LLM-based insights)  
- AWS (for deployment)
